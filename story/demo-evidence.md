## A short manual demo check

- [ ] Start at a real site and a supported UTC range.
- [ ] Read sunlight and Earth visibility separately.
- [ ] Change the date and confirm that both displayed dates and data update.
- [ ] Compare two sites for the same interval.
- [ ] Check that an unavailable date shows a clear message.
- [ ] Check that colour is accompanied by labels or a legend.
- [ ] Check that displayed numbers agree with the data owner's verified outputs.
- [ ] Capture a screenshot and write down the site, range and app revision.
- [ ] Repeat the recorded path once without prompting.

These are planned checks, not completed test results.
