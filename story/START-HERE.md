## Git in plain language

A repository is the shared project and its history. A branch is a separate line of work. A commit records a snapshot; a push uploads commits to GitHub. A pull request proposes those changes to the shared project.

Our reference changes should stay on koum/story-preparation until reviewed. Updating a project from the remote must preserve drafts and respect the story/-only boundary; do not pull code changes merely to prepare these references.
